# Week 2 — Linux Fundamentals & Shell Scripting 

## Overview

Week 2 of my AWS re/Start journey focused on Linux fundamentals and working with the command line.

After deploying my first EC2 web server in Week 1, this week helped me understand the operating system and command-line environment that powers many cloud workloads.

Instead of relying on a graphical interface, I spent the week working directly with Linux commands, files, permissions, processes, services, and Bash.
